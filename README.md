# filtapp
---
* **КОНСОЛЬНАЯ УТИЛИТА ОТОБРАЖЕНИЯ АЧХ СИГНАЛА**

принцип работы:
| :--- | :--- |
| `filtapp --lowpass 1/4` | фильтрация сигнала + вывод полученного спектра в консоль |
| filtapp print | вывод спектра в консоль |

* зависимости
1. gcc/clang
2. make

* репозиторий с проектом поддерживает автомерж
